# Onixus light-background package

Use these white-background metallic PNGs on white layouts. Graphite lettering and darker metallic edges improve contrast. Workspace, Mail, CRM, Signal and corrected Chat marks are included. Keep each logo intact with generous clear space.

The supplied SVG layouts embed the new PNG artwork and have editable text. They are not vector logo masters. Export social SVG layouts to PNG/JPG before uploading to social platforms. Print proofing and vector reconstruction are still needed for signage. This package does not include a transparent master.

The light kit is a separate companion to the jet-black kit; neither overwrites the other. HTML documents support browser printing. No website or product logo assets were replaced by making this package.
